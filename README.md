# AYAREA

Sitio estático bilingüe para ayarea.com. Publicación mediante GitHub Pages.

## Previsualizar

Desde la raíz del proyecto: `python -m http.server 8000`.
Abrir http://localhost:8000.

## Contenido

- `index.html`: contenido en español e inglés y selector de idioma.
- `assets/ayarea.css` y `assets/comp-layout.css`: diseño y composición adaptable.
- `assets/ayarea-symbol.svg`: símbolo de marca.
- `CNAME`: dominio personalizado.
